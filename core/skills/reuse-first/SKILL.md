# Reuse First

Before building, look for what already exists:

- Code in the repo that does the same or a similar job. Follow its pattern.
- Libraries, packages or modules that already solve it.
- Open issues, PRs and MRs on the same problem. Join or review them instead of opening a duplicate.

Say what you found in 1 line, even when it's nothing. Build new only when nothing fits, and say why the closest match didn't.
