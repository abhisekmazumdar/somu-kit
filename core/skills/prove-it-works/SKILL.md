# Prove It Works

Verify against the real thing: run the feature, read the actual value, inspect the diff. Proxies don't count ("it compiles", a self-report, cached output). When a check fails, suspect the way you checked before the system.

Show the proof instead of describing it. Attach test output, a screenshot or a GIF. "I tested it" with nothing attached is not proof.

Script the check when you can, so it can be rerun.
